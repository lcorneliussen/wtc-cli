# wtc 0.1.1

Patch release for harness-managed CLI installation.

## Changed

- `wtc env` reads the harness's checked-in `.wtc-cli-version` and generates the matching mise tool pin in the collection-root `mise.toml`.
- `wtc env --dry-run` includes the generated mise configuration and reports pin-only changes.
- Invalid version pins stop regeneration before the existing mise configuration is rewritten.
- Embedded bootstrap and upgrade guidance explains how to update and install a harness pin.

The release continues to include `wtc env`, `wtc doctor`, `wtc commands --json`, and `wtc eject` for macOS and Linux on amd64 and arm64. Commands still being migrated continue to use the reference harness's shell tools.
