# wtc 0.1.3

This release adds collection-local PR records, registry refresh, and MCP configuration rendering, plus customization hooks for migrated commands.

## New commands

- `wtc pr path|list|enlist|unlist` manages the collection's local `.wtc-prs` records.
- `wtc registry refresh` updates the local bare-owner map and reports registry mismatches.
- `wtc mcp render [--dry-run]` renders Claude Code, Cursor, and Codex MCP server settings from the harness registry. It preserves unrelated settings and manually configured servers, validates the registry before writing, and replaces changed files atomically.
- `wtc customize` prints the bundled guide to harness and repository hooks. The `wtc-customize` skill can be ejected for local adaptation.

## Improved configuration

- `wtc env` retains additional collection-root `[mise.tools]` entries while keeping the CLI version pin in `.wtc-cli-version` authoritative.
- Migrated commands run executable harness pre/post hooks. Pre-hooks can stop an action; post-hook failures are reported as warnings.
- MCP rendering supports JSON-array arguments for values containing spaces and uses the interpolation syntax expected by each agent. It checks schema versions, variable names, and output validity.
- PR and registry inputs receive stricter validation before local files or hooks are touched.

## Upgrade

Set the harness's `.wtc-cli-version` to `0.1.3`, regenerate the collection environment, and run `mise install` in the collection. Existing shell tools remain available during the command migration. See `MIGRATION.md` for the remaining commands and compatibility work.

macOS and Linux release archives are built by the release workflow; their checksums are published with the assets.
