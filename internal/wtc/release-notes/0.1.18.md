# wtc 0.1.18

This release improves context for repeated public PR reviews with `wtc review bundle`.

## Review bundles

- Later rounds carry earlier public review summaries and posted inline-comment keys for the same PR. Bundles marked private are excluded from a `--public` bundle.
- GitHub PR bundles include author replies after the latest local review status. Posted reviewer findings stay out of the reply transcript while their keys remain available to avoid duplicate inline comments.
- If GitHub comments are unavailable, the local review bundle still builds and reports a warning. Synthetic tests cover both retrieval and this fallback; a live public PR bundle carried earlier summaries into the next round.

The native bundle command still requires `--public --no-catch-up`. Private dependency snapshots, concern overlays, Bitbucket reply context, and native catch-up remain on the migration checklist. Inspect any public bundle before giving it to an external reviewer, because PR text and comments are included.

## Upgrade

Pin `0.1.18` in `.wtc-cli-version`, refresh the collection environment, and run `mise install`.

macOS and Linux archives and checksums are published with this release.
