# wtc 0.1.17

This release adds `wtc browse`, bringing collection selection, Neovim launch, and herdr pane routing into the CLI.

## Browse

- Run `wtc browse` for the current collection, or `wtc browse <collection>` for a named collection. In a terminal it opens Neovim in that window. From an agent pane it uses the selected collection's browse pane and leaves the agent pane available; `--here` explicitly uses the current terminal.
- The multi-repository Neovim view is bundled in the release. It keeps one tab per worktree, the collection change index, and the existing listen-socket spelling used by browse integrations, including shortened names for long collection paths.
- A harness can replace the bundled view with `harness/overlays/browse/wtc-browse.lua`. The selected collection path is available to that view as `vim.g.wtc_browse_root`. The `wtc customize` guide and browse skill describe the extension point.
- Agent routing uses the selected collection's existing compatibility entry point when present and can run the CLI directly in a harness without that script. Busy panes are left in place.

## Upgrade

Pin `0.1.17` in the harness's `.wtc-cli-version`, refresh the collection environment, and run `mise install`. The reference harness's matching-pin browse shim follows this release. Neovim is required to use `wtc browse`; other CLI commands remain available without it.

macOS and Linux archives and checksums are published with this release.
