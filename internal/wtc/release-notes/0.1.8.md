# wtc 0.1.8

This release adds native rendering of collection skills and agent setup.

## New command

- `wtc skills render` exposes embedded `wtc-*` skills in `.claude/skills` and `.agents/skills`. Skills checked into `harness/skills/<name>/SKILL.md` replace embedded defaults; full replacements in `harness/overlays/skills/<name>/SKILL.md` take precedence. Hand-authored skill destinations are preserved, and stale links owned by the renderer are pruned.
- The command wires the collection's `AGENTS.md` entry point and agent hook links, writes the generated `.envrc`, and refreshes `.env.toolchain`. It uses an embedded entry template if the harness has none.
- `--seed-scope` seeds `WTC-SCOPE.md` only when absent. `--dry-run` previews without writing. Explicit `--all` processes every collection in the workspace and reports individual failures; use it when target collections have matching CLI pins.
- Optional harness hooks `skills.render.pre.sh` and `skills.render.post.sh` can customize the lifecycle. `wtc customize` documents skill layering and the hook contract.

Section patch overlays and a skill drift report remain on the migration checklist.

## Upgrade

Set the harness's `.wtc-cli-version` to `0.1.8`, regenerate the collection environment, and run `mise install`. Existing shell entry points remain available during the compatibility rollout. The remaining command and TUI ports are listed in `MIGRATION.md`.

macOS and Linux archives and checksums are published with this release.
