# wtc 0.1.21

## Native workspace opening

`wtc open` now creates and repairs herdr workspaces. It supports `--list` and `--dry-run` for inspection, `--wide` and `--narrow` for explicit layout changes, and `--all` when you intentionally select every collection in a workspace. It keeps running panes during layout changes and starts an agent, browser, or status view only when its pane is idle.

`wtc new --open` and automatic opening of a new collection use the native command. Opening now reports pane startup and inspection failures instead of returning success with an incomplete workspace. Agent names that exceed herdr's length limit retain a stable collection-specific suffix.

The bundled `wtc-open` skill and herdr guide use the native command. Existing shell entry points can dispatch to this version when their collection pin and installed binary match.

## Upgrade

Set the collection's `.wtc-cli-version` to `0.1.21`, install the pinned CLI with `mise install`, then run `wtc open --list` or `wtc open --dry-run` to inspect the current workspace. Use `wtc open` to create or repair its panes.
