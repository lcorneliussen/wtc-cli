# wtc 0.1.32

## Interactive status by default

`wtc status` now opens the live TUI when both stdin and stdout are terminals. The live view keeps the table visible while refreshing and offers a refresh log with `l` or a click on “refreshing”. Use `q` to leave it.

For a single terminal snapshot, use `wtc status --no-watch`. JSON, Markdown, ANSI, cached, preview, and redirected output remain one-shot. Interactive one-shot collection reports progress on stderr unless `--silent` is set, including when the configured watch interval is zero.

The bundled status skill and command help describe the new default. No configuration change is needed for status panes that already pass `--tui`.

## Verification

The exact merge commit passed the main branch CLI test and build workflow. The command test suite and a pseudo-terminal smoke run verified that bare interactive status enters the TUI and exits on `q`.
