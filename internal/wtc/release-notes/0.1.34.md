# wtc 0.1.34

## Responsive inventory views

`wtc secrets list` and `wtc env list` now open a scrollable terminal view when run interactively. Each row stays on one line and adapts to the pane width. Short scope and state labels keep the list readable; the selected row shows additional metadata below it. Use arrow keys or `j` and `k` to move, Page Up and Page Down for larger moves, and `q` to exit.

Use `--no-tui` for a compact one-shot table, or `--json` for the full structured inventory. An explicit `--tui=false` also selects one-shot output. Redirected and piped output remains one-shot automatically. The commands continue to show names and paths only, never secret or environment values.

## Verification

The CLI test suite passed, including layout checks at narrow and wide terminal sizes, resize backfill, and column alignment. Pseudo-terminal checks verified both interactive views at 42 columns, keyboard exit, and explicit one-shot behavior.
