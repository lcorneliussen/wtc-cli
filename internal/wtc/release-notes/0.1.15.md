# wtc 0.1.15

This release adds native collection catch-up with guarded Git reconciliation and readable or machine-readable reports.

## New command

- `wtc catch-up` updates selected collections and repositories against their shared bare owners. `--all` explicitly selects a workspace sweep; `--repos` and `--harness-only` narrow the target set.
- `--dry-run` previews actions without fetching or changing worktrees. `--json` emits the catch-up report, and `--report` writes a readable report.
- Live branches are merged without rebasing. Dirty local changes are stashed with a recovery reference and restored; uncertain pull-request state or an in-progress Git operation leaves the worktree for its owner to resolve.
- Target refresh hooks run after a successful update. `--reload-status` touches only a verified status pane and leaves unrelated processes alone.

## Upgrade

Pin `0.1.15` in the harness's `.wtc-cli-version`, refresh the collection environment, and run `mise install`. Existing shell catch-up entry points remain available until their matching-pin shims are updated.

macOS and Linux archives and checksums are published with this release.
