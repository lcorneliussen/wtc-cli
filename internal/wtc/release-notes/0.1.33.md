# wtc 0.1.33

## Secret and environment inventories

`wtc secrets list` shows the paths available in the control root, whether each file is shared with collections that check out its repository, and its state in the selected collection. States include linked, available, locally overridden, not gitignored, and excluded by the production-path guard. The inventory also identifies the collection-local variable file. Use `--repo` to narrow the list and `--json` for scripts.

`wtc env list` shows variable names and their source: machine defaults, generated collection environment, or collection-local overrides. It never prints variable values. Both inventory commands are read-only.

## Explicit environment setup

`wtc env` now shows its subcommands. Run `wtc env setup` to regenerate the collection environment and mise configuration. Existing flagged calls such as `wtc env --collection DIR` remain compatible with the setup behavior.

## Verification

The CLI test suite and synthetic inventory fixtures passed. The fixtures cover shared and local scope, link states, production exclusions, repository filtering, and JSON that contains no secret values. The exact merge commit passed main CI.
