# wtc 0.1.9

This patch release makes `wtc env` trust the collection's generated `mise.toml` after a successful write.

## Fix

- When mise is installed, `wtc env` runs `mise trust` for the collection config after refreshing it. A trust failure is reported instead of leaving the new tool pin silently unavailable.
- Dry runs still write nothing, and environment generation still works on machines without mise.

## Upgrade

Set the harness's `.wtc-cli-version` to `0.1.9`, refresh the collection environment, and run `mise install`. The `refresh-env.sh` compatibility entry point can then select this release from the target collection's pin. Native `wtc env --all` remains on the migration checklist; the shell sweep continues to select each target separately.

macOS and Linux archives and checksums are published with this release.
