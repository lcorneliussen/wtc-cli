# wtc 0.1.22

## Review bundle migration

`wtc review bundle` now builds private review bundles with registry-defined upstream and downstream snapshots, local concern overlays, related enlisted PR patches, and prior review context. For a known PR at `HEAD`, it checks out the PR branch and catches up the current collection before taking the diff. `--no-catch-up` skips that refresh while retaining branch checkout. Branch-only reviews use current local refs.

`--public` excludes related repository snapshots, patches, and local overlays. If forge PR metadata is unavailable, a numbered review requires a matching local PR enlistment before it can use the requested PR identity. Consumer `new/` snapshots likewise require an enlisted branch. Native bundles can read prior summaries from older shell bundles without executing their manifest files.

## Upgrade

Set the harness's `.wtc-cli-version` to `0.1.22`, run `mise install` in the collection, and use `wtc review bundle <repo> [pr-number]`. Inspect a public bundle before sharing it with an external reviewer or posting its review output.
