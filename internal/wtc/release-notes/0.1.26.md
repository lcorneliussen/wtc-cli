# wtc 0.1.26

## Status refresh progress and speed

- `wtc status` now prints elapsed-time collector steps when run in an interactive terminal. Use `--silent` to suppress progress. JSON, Markdown, and captured output remain clean.
- `wtc status --tui` shows the current refresh step. Click “refreshing” or press `l` to open its refresh log. The log also reports failed ref fetches and the local-ref fallback.
- Pull request detail checks now run with at most four concurrent forge calls while preserving result order.
- Active pull requests keep the 90-second forge cache. Merged pull request details can be reused for 24 hours, avoiding repeated checks of completed work. Set `WTC_FORGE_CACHE_AGE` to override both cache ages.

The status snapshot schema and existing command output formats are unchanged.
