# wtc 0.1.20

## Local review workflow

- `wtc review run <bundle> --post` now creates a progress comment before the separate reviewers start, then updates that same comment with the final summary or a failure state.
- The bundled `wtc-local-review` skill and collection guidance describe how to build, inspect, post, address, and rerun a local PR review. The bundled PR procedure uses `wtc review ready` to promote a draft.
- `wtc review ready` requires a current trusted review with zero open blockers, even if a comment reports a passing verdict. The runner aligns its visible summary heading with the enforced verdict and lets the lead record a refuted or downgraded finding before blocker counting.

## Upgrade

Pin `0.1.20` in the harness `.wtc-cli-version`, refresh the collection environment, run `mise install`, and render skills to make `wtc-local-review` available.
