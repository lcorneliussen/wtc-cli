# wtc 0.1.27

## Status TUI links, color, and faster refreshes

- PR numbers in repository rows and the PR list are now underlined terminal hyperlinks. Build references use the same link style. In terminals that reserve mouse input for the TUI, use the terminal's modifier-click gesture; ordinary clicks also open PR and build targets when mouse targets are enabled.
- The status TUI restores color hierarchy for headings, clickable references, local changes, warnings, and merged PRs. `NO_COLOR` suppresses styling while preserving terminal hyperlinks. `TERM=dumb` uses plain labels without control sequences. One-shot status output retains its plain format.
- On first recognizing a merged pull request with settled checks, `wtc status` records its merge time and final check result in the collection-local `.wtc-prs` file. Later refreshes reuse these final facts instead of querying the forge again. Existing registry rows remain readable by older shell tools, and merged PRs still follow the configured archive cutoff.
- GitHub merge timestamps and dated Bitbucket merge activity events supply the final merge time. Registry updates are serialized, and retirement removes the registry lock file.
- The refresh log separates recorded merges from live PR checks, so a large historical registry no longer looks like a large live queue.

The status JSON schema adds an optional PR URL on repository rows. Existing fields and command output formats remain compatible.
