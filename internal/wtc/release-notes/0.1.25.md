# wtc 0.1.25

## Skill overlays and drift review

Harnesses can replace one H2 section of a versioned skill by adding a complete section under `overlays/skills/<name>/sections/`. `wtc skills render` combines it with the embedded or harness skill and rejects missing or duplicate headings, conflicting full overlays, and malformed code fences before writing generated skills.

The new read-only `wtc skills diff` command lists full overrides and section patches. Use `--changes` to see added and removed lines, or `--json` for automation. After reviewing a patch, record the reported base SHA-256 in `overlays/skills/<name>/.wtc-base.sha256`; a later base change is reported as drift, and rendering stops until the patch is reviewed against the new base. A renamed or removed heading remains visible in the diff report with an applicability error.

## Upgrade

Set the harness's `.wtc-cli-version` to `0.1.25`, refresh the collection's generated `mise.toml`, and run `mise install`. Existing full skill overrides continue to work. Section patches are opt-in.
