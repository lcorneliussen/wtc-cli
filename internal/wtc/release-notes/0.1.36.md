# wtc 0.1.36

## Status PR ordering

`wtc status` now shows open pull requests above drafts in the interactive TUI and Markdown output. It keeps enlistment order within each group. Checked-out merged work still appears with its catch-up warning, and completed PRs remain muted below active work. The ordering also applies when rendering a cached snapshot.

`go test ./...`, `go vet ./...`, the PR check, and the exact main CI run passed. Tests cover both renderers and the existing catch-up and merged-row layout.
