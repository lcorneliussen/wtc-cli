# wtc 0.1.19

This release adds Bitbucket PR reply context to native review bundles.

## Review bundles

- `wtc review bundle` now reads Bitbucket PR comments through the supported JSON command. Replies after the latest local review status appear in `prior/comments.md`; posted inline finding keys remain in `prior/inline-keys.txt` without repeating the findings as replies.
- An unavailable or incomplete comment response produces a warning while leaving the local diff bundle usable. A response at the 1,000-comment request limit is treated as incomplete, since the CLI's count does not reliably establish the remote total.
- The command help now calls the result a local review bundle. Inspect its PR text, comments, diff, and prior summaries before sharing it.

The native bundle command still requires `--public --no-catch-up`. Private dependency snapshots, concern overlays, and native catch-up remain on the migration checklist. The existing shell workflow remains available for those cases.

## Upgrade

Pin `0.1.19` in `.wtc-cli-version`, refresh the collection environment, and run `mise install`.

macOS and Linux archives and checksums are published with this release.
