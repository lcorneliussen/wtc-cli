# wtc 0.1.12

This release adds native retirement for finished worktree collections.

## New command

- `wtc retire <collection>` inspects every repository worktree for uncommitted changes and commits absent from remote refs before removing anything. `--force` is available when that local work has been checked and is deliberately disposable.
- Retirement runs each repository's `harness:teardown` mise task or executable `.harness/teardown.sh`, removes the worktrees and generated collection files, closes the collection's herdr workspace, and leaves remote branches and shared bare owners intact.
- Hand-authored agent settings, skill overrides, merged MCP configuration, and other unexpected files remain in the collection folder for inspection. The CLI reports those leftovers.
- `retire.pre` and `retire.post` harness hooks allow collection-level customization. The embedded `wtc-retire` skill and `wtc customize` guide describe the new path.

## Upgrade

Pin `0.1.12` in the harness's `.wtc-cli-version`, refresh the collection environment, and run `mise install`. The shell `retire.sh` entry point remains available; its matching-pin CLI shim follows separately.

macOS and Linux archives and checksums are published with this release.
