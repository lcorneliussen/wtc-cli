# wtc 0.1.6

This release adds a native agent shell toolchain environment command.

## New command

- `wtc agent-env` prints shell exports that prepend the collection's sibling mise bins to `PATH`. Product repository bins come before harness and collection pins, so agent shells use the repository's tool versions.
- `--write` refreshes the machine-local `.env.toolchain` cache without printing, and `--print-path` prints only `WTC_TOOLCHAIN_PATH`.
- `--wrap` reads a PreToolUse JSON event from stdin and emits an updated command that loads the toolchain environment. Invalid or unsupported events leave the command untouched.
- If mise is unavailable in a bare agent shell, the command retains an existing useful cache instead of clearing it. `--collection` selects a collection explicitly for each mode.

## Upgrade

Set the harness's `.wtc-cli-version` to `0.1.6`, regenerate the collection environment, and run `mise install` in the collection. Shell entry points continue to work during the migration; a subsequent harness update routes `agent-env.sh` through this released command when available.

The broader command and TUI migration remains in progress; see `MIGRATION.md`. macOS and Linux archives and checksums are published with this release.
