# wtc 0.1.29

## Status link hierarchy

- Repository and branch names remain terminal links, now shown in the ordinary row tones. Detached development branches stay muted.
- PR links keep their accent. Linked build results use green for success, amber for pending, and red for failure or error, while still opening the exact build URL.
- Press `?` in the status TUI to see what the PR table's C, M, and R columns mean: checks, mergeability, and reviews.

The change is visual; status snapshots and link targets are unchanged.
