# wtc 0.1.23

## Review bundle follow-up

`wtc review bundle --dir` now looks in both the collection review directory and the custom directory's parent when choosing the next review round. Successive custom-directory bundles advance their round number and carry prior summaries and inline-comment keys forward, matching the shell review workflow.

The binary's bundled `wtc-local-review` skill now explains native private bundles, PR branch checkout and catch-up, branch-only local refs, and inspecting generated review text before posting.

## Upgrade

Set the harness's `.wtc-cli-version` to `0.1.23` and run `mise install` in the collection. If you place bundles outside `.wtc-reviews`, the native command now preserves automatic round history in that location.

## Verification

The pull request passed Go tests, vet, current-head CI, and independent local review. Main CI passed on the release commit. The release workflow built macOS and Linux archives with checksums.
