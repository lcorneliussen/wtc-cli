# wtc 0.1.13

**For workspace-wide sweeps, upgrade to v0.1.14.** In v0.1.13, `wtc mcp render --all` runs each target collection's MCP lifecycle hooks. v0.1.14 makes those hooks opt-in for sweeps.

This release adds native workspace-wide MCP configuration rendering.

## New behavior

- `wtc mcp render --all` visits each direct collection in the workspace and renders that collection's own `harness/.mcp-servers.yml` into its agent configuration files.
- The sweep continues if one collection fails and reports each result. It exits nonzero if any collection fails; `--json` includes the per-collection results and failure count.
- Collections that predate the MCP registry are skipped without changing their existing configuration. `--dry-run` previews changes without writing files or running hooks.
- Workspace sweeps omit missing-credential warnings because the invoking shell cannot represent every collection's agent environment. A single-collection render still reports variables missing from its current shell.

## Upgrade

Pin `0.1.14` in the harness's `.wtc-cli-version`, refresh the collection environment, and run `mise install`. The `link-mcp.sh` compatibility entry point remains available.

macOS and Linux archives and checksums are published with this release.
