# wtc 0.1.30

## Self-retire from a Herdr collection

Run `wtc retire .` from the collection's own Herdr workspace. After the usual dirty and unpushed work checks, the CLI creates or reuses a `--cleanup--` workspace in the same session and runs the final teardown there. The cleanup pane stays open with the result after the target workspace closes.

The worker verifies the source and cleanup workspace IDs, waits for the initiating agent to finish, and refuses to close a second agent pane. It closes the source workspace before teardown and checks for dirty or unpushed work again afterward, so changes made during handoff block deletion. It retains remote branches and bare owners. `wtc retire <other>` remains the direct path when called from a different collection, and a target argument is still required.

The retire guidance and new-collection handoff note now describe the self-retire command. A normal Git checkout is rejected during preflight because retirement only removes linked worktrees.
