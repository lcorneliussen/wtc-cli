# wtc 0.1.37

## Direct CLI entry points

`wtc open` starts the status and browse panes with `wtc status --tui` and `wtc browse --here`. Catch-up recognizes and restarts a native status pane. Collection instructions and embedded skills now use direct `wtc` commands for routine collection work.

## Native catch-up maintenance

Catch-up refreshes collection environment, skills, MCP configuration, and secret links through native CLI actions. It reports a target collection that cannot be opened as a failed maintenance action. The environment step validates the mise configuration before replacing generated files, and skips an environment rewrite when the rendered content is unchanged.

## Agent toolchain setup

`wtc agent-env --wrap` injects the computed toolchain exports directly into agent commands. Workspace creation no longer points `BASH_ENV` at a harness script. Generated `.envrc` files remain replaceable, while a local override that only mentions the generated marker is preserved.

## Verification

The PR's checks and the exact merge commit's main CI passed. `go test ./...` and `go vet ./...` passed locally. Tests cover direct pane commands, native catch-up actions, agent environment wrapping, generated-file ownership, and failure reporting.
