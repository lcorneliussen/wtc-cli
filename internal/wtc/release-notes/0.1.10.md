# wtc 0.1.10

This release adds native collection creation with `wtc new`.

## New command

- Create a collection from a slug, an issue (`--issue`), a tracker key (`--tracker`), or a GitHub pull request (`--pr`). Ordinary worktrees start detached at the development tip; an explicit `--branch` checks out a branch.
- Fetch shared bare owners, allocate a collection port block, render the environment, skills, and MCP configuration, link gitignored machine-local files, run repository init hooks, and write a launch note.
- Review collections verify the exact PR head and configure its source remote for pushes. If the PR branch is already checked out elsewhere, the new collection uses a distinct local review branch and records an explicit push command.

## Upgrade

Pin `0.1.10` in the harness's `.wtc-cli-version`, refresh the collection environment, and run `mise install`. The existing `branch-off.sh` entry point remains available; its target-aware CLI shim will be rolled out separately.

macOS and Linux archives and checksums are published with this release.
