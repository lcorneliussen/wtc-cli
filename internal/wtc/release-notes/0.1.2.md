# wtc 0.1.2

Compatibility update for harness registry layouts.

## Changed

- `wtc` accepts registries using `repos`, `repositories`, or `selected` with categorized `non_default` entries.
- Basic commands retain additional per-repository metadata instead of rejecting fields they do not use. Repository name and port validation still applies.

This patch retains the commands and release platforms from v0.1.1. Harnesses with additional generated collection-root mise tools should continue using their shell env generator until CLI issue #3 is resolved.
