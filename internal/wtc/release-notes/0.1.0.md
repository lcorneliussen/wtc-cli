# wtc 0.1.0

First release of the worktree collection CLI.

## Included

- `wtc env` regenerates a collection's environment while preserving its port allocation and local overrides.
- `wtc doctor` checks the collection registry, compatibility requirement, and local dependencies.
- `wtc commands --json` exposes the available command surface to automation.
- `wtc eject` copies selected embedded skills, instructions, and templates into a harness for customization without overwriting existing files.

## Install and scope

Release archives contain a single `wtc` binary for macOS and Linux on amd64 and arm64. The `checksums.txt` asset lists SHA-256 digests. A harness can pin this release through mise with `"github:lcorneliussen/wtc-cli" = "0.1.0"`.

This release begins the migration. Commands that have not moved to `wtc` continue to run through the reference harness's shell tools. Collection-root mise pin generation is planned for a subsequent release; until then, a generated `mise.toml` will not retain a manually added CLI pin.
