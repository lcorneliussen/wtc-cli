# wtc 0.1.53

The `wtc status` services table now shows what 0.1.52 added to `wtc svc` and the OpenClaw card: a ready service or tunnel that doesn't answer now, and a tunnel whose provider isn't signed in.

## Services and tunnels

- **The `wtc status` services table shows it too.** A ready service or
  tunnel that doesn't answer now shows `no answer`, and a live tunnel
  whose provider isn't signed in shows `login`, both in red, with the
  details on hover
  ([#174](https://github.com/lcorneliussen/wtc-cli/issues/174)).

## Upgrade

- **Install the new `wtc`.** On OpenClaw gateways, also run `wtc openclaw
  install`.
