# wtc 0.1.24

## Review run statistics

`wtc review run` now records token usage, cache usage, turns, cost when reported, and elapsed time for each concern and the lead agent. Its summary includes a per-agent table and totals. The runner reads usage from Codex, Claude, and Grok output and preserves statistics supplied by custom launchers through `WTC_REVIEW_STATS_FILE`.

Agent chains now add usage and elapsed time from rate-limited attempts before trying a fallback. A dash means the agent did not report a value; a plus sign marks a partial total. Statistics from previous runs are cleared before a new run.

## Upgrade

Set the harness's `.wtc-cli-version` to `0.1.24` and run `mise install` in the collection. The native `wtc review run` command is ready for use; existing review bundles remain compatible.
