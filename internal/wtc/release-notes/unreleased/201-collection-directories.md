## Rename preparation

- **Existing collections can use `.taba/config` and `.taba/dev`.** Normal and gateway discovery, registry updates and early dev handover select each namespace independently with legacy-first precedence, so generated `.wtc` files cannot hide alternate user configuration. Fresh collections, installed dev builds and rendered defaults retain legacy paths. Dev removal clears both slots without following linked parents; retirement clears both local registry slots and checks retained discovery markers before teardown, while retaining local configuration. Runtime, watcher and review namespaces remain further phase-0 work. See [collection directory inputs](https://github.com/lcorneliussen/wtc-cli/blob/main/docs/rename-collection-directories.md) and [#201](https://github.com/lcorneliussen/wtc-cli/issues/201).
