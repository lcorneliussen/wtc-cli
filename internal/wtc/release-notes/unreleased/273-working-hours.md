### Private working hours and gradual wrap-up

- Add explicit `wtc hours setup` / `edit` / `view` / `clear`, personal defaults
  and project overrides shared across collections using one private local record.
  Nothing is configured or activated by default.
- Expose fresh JSON phase, current/next-window and transition facts with IANA
  timezone/DST, split and overnight windows, finite project extensions and an
  atomic shared outside-window reminder claim. Local status offers a quiet hint.
- Ship portable coworker guidance for focus, saved-work handoff and quiet
  already-authorized independent work. Agent enforcement remains guidance-only;
  no daemon, automatic messaging or cancellation is installed. OpenClaw stays
  unconfigured pending an authenticated-person and lifecycle adapter.

See [working-hours reference](https://github.com/lcorneliussen/wtc-cli/blob/main/docs/working-hours.md).
