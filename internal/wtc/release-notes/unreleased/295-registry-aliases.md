## Rename

- **Registry aliases let a repository be renamed without breaking collections.** Rename an entry in `.harness-repos.yml` and list the old name under `aliases:`. Existing collections keep their old folder name and every command accepts either name. The existing `.bare/<old>.git` owner keeps serving all collections; it is not cloned again. After a rename on the same forge host and owner, catch-up and checkouts point its `origin` at the changed registry `remote` and report it once. Port variables are emitted under both names, new collections use the new folder name, and `wtc status` marks old folders "renamed to …". Ad-hoc collections don't support aliases yet; keep using the old URL there. See [renaming a repository](https://github.com/lcorneliussen/taba/blob/main/docs/renaming-repositories.md) ([#295](https://github.com/lcorneliussen/taba/issues/295)).
