## OpenClaw

- **Sandbox sessions discover operator-allowed gateway projects.** Project names and repository default branches can be used in add-repo plans through the sandbox Git service. Discovery is denied by default, with an explicit per-agent allowlist, and grants no additional Git, clone or publication access. See [project discovery in a sandbox](https://github.com/lcorneliussen/wtc-cli/blob/main/docs/sandbox-projects.md) for operator setup ([#171](https://github.com/lcorneliussen/wtc-cli/issues/171)).
