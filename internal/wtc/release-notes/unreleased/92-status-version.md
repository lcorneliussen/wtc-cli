## Status

- **See the running CLI version in status.** The live header keeps the command
  and timing together, with its own build version in a muted suffix and a
  terminal hyperlink to stable release notes. The suffix is available before
  collection finishes and may clip in narrow terminals. Dev, prerelease and
  unknown builds stay honest without
  invented release URLs. Local text and JSON snapshots record their producer's
  CLI version; cached rows never replace the live TUI's running version.
