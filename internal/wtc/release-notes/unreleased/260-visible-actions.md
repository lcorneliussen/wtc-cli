## Status and OpenClaw

- **Dense collection controls.** Small outlined actions have visible hover/focus feedback and remain in the top bar when the card is collapsed. Header-free repository rows keep branch, counts, PR status and progress on one line where width permits. Other active PRs are muted number links; completed PR counts open the full PR history in the taba sidebar. A clean catch-up runs deterministically; the gateway’s local merge and separate personal PR-update push are named explicitly.
