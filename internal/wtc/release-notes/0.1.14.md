# wtc 0.1.14

This release adds workspace-wide environment refresh and makes collection-wide maintenance safer by default.

## New and changed commands

- `wtc env --all` refreshes each direct collection from its own harness registry. It continues after a target fails, reports each result, and exits nonzero if the sweep is incomplete. `--json` provides the per-collection results.
- Environment dry-run sweeps reserve port blocks in memory. A preview of multiple new collections now shows the same distinct port blocks a write would assign.
- `wtc env --all` and `wtc mcp render --all` skip target lifecycle hooks by default. Environment sweeps also leave each target's mise trust state alone. Use `--run-hooks` only when every target is trusted and the hooks are meant to run.
- `--skip-hooks` is available when a compatibility script enters one target while carrying out a workspace sweep. A normal single-collection command keeps its existing hook behavior unless this flag is given.

## Upgrade

Pin `0.1.14` in the harness's `.wtc-cli-version`, refresh the collection environment, and run `mise install`. The shell entry points remain available while their matching-pin dispatch is rolled out.

macOS and Linux archives and checksums are published with this release.
