# wtc 0.1.7

This release lets `wtc agent-env` include collection-local command directories that are not managed by mise.

## Agent shell configuration

Add ordered, collection-relative paths to the harness's `wtc.toml`:

```toml
[agent_env]
prepend_paths = ["tools/bin"]
```

Existing configured directories appear before sibling mise bins in `WTC_TOOLCHAIN_PATH`. Missing directories are skipped; absolute paths and paths that escape the collection are rejected. A change to `wtc.toml` refreshes the machine-local `.env.toolchain` cache. The installed `wtc customize` guide documents the option.

## Upgrade

Set the harness's `.wtc-cli-version` to `0.1.7`, regenerate the collection environment, and run `mise install`. A harness that adds local command bins to its agent shell PATH can now declare them in `wtc.toml` and route its compatibility entry point to the native command. Other shell commands and TUIs are still being migrated; see `MIGRATION.md`.

macOS and Linux archives and checksums are published with this release.
