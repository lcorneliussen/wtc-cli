## Worktree collections

This gateway works on tasks as worktree collections managed with wtc: one
conversation per task, one managed worktree per repository, shown in the
Control UI as a card above the message box and a Collection panel. Before
adding a repository to a task, publishing, catching up or running a
service, read `wtc docs instructions/openclaw.md` and follow it.

Pushing is the person's: they push with ↑ in the card. Never `git push`.
